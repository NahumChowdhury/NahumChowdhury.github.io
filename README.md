# Nahum Chowdhury — Portfolio

A responsive, light-theme personal portfolio built with plain HTML, CSS and vanilla JavaScript.

## Files

- `index.html` — page structure and portfolio content
- `style.css` — responsive styling and visual design
- `script.js` — mobile navigation, section highlighting and subtle reveal effects
- `assets/profile.png` — supplied portrait image

## Preview locally

Open `index.html` in a browser. An internet connection is needed to load the Google Fonts; system fallbacks are included.

## Publish with GitHub Pages

1. Upload the contents of this folder to the root of `NahumChowdhury/NahumChowdhury.github.io`.
2. Keep the `assets` folder alongside `index.html`.
3. In the repository, open **Settings → Pages** and confirm the source is the `main` branch and `/ (root)`.
4. Wait for GitHub Pages to publish the update.

## Before publishing

- Review the skills list and project descriptions for accuracy.
- Add a LinkedIn profile only if you want it public.
- Add `cv.pdf` only after the CV is ready. This version intentionally has no broken or placeholder CV download button.
- Add project screenshots or repository/demo links only when they are ready and public.
